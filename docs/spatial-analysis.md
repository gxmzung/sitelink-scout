# 건축 공간 및 무선 신호 분석 계획

**1차 현장 후보:** 배재대학교 캠퍼스(구체적 건물·층·실은 미선정)  
**건축 연구 방향:** 박하음 검토 예정 · **측정·개발:** 이영준

## 1. 연구 질문
건물의 평면 구성, 철근콘크리트·경량 칸막이·유리·금속 설비 및 공간 이용 인원이 2.4 GHz Wi-Fi RSSI와 어떤 관계를 보이는가?

**RSSI 차이만으로 특정 재료의 고유 전파 감쇠량을 판정할 수 없습니다.**

## 2. 배재대학교 실증 공간 선정 기준

| 후보 유형 | 연구 가치 | 사전 확인 사항 |
|---|---|---|
| 강의실과 인접 복도 | 출입문·벽체 경계 비교 | 강의 방해 여부, 공간 이용 승인 |
| 공용 학습공간 | 이용 인원 변화 관찰 | 촬영·개인정보 제한, 측정 시간 |
| 실습실·프로젝트 공간 | 이동식 가구·칸막이 비교 | 장비 반입·전원·안전 승인 |

위 표는 **공간 유형별 후보**일 뿐 실제 배재대학교 건물의 벽체 재료나 접근 가능성을 확인한 결과가 아닙니다. 우선 1개 층, 2~3개 공간, 고정 AP 1개와 측정점 여러 개로 범위를 좁힙니다.

## 3. 기록할 건축 변수

| 변수 | 기록 항목 | 주요 교란요인 |
|---|---|---|
| 철근콘크리트 | 벽 위치·두께·배근 정보(확인 가능한 경우) | 반사, 배근, 입사각 |
| 경량 벽체 | 구조·마감·두께 | 내부 스터드, 개구부, 수분 |
| 유리 | 종류·코팅·두께 | 금속 코팅, 입사각 |
| 금속 설비 | 위치·크기 | 다중경로·반사 |
| 이동식 자재 | 종류·적치 위치 | 이동 및 배치 변화 |
| 점유 조건 | 인원 수·공간 면적·배치 | 자세, 이동, 인체 방향 |

실제 현장 확인 전에는 재료 종류를 단정하지 않습니다.

## 4. 실험 시나리오
- **S01 개방 기준:** AP와 수신기 위치 고정, 장애물 추가 없음
- **S02 가변 칸막이:** 동일 지점에서 칸막이 전후 비교(허가 시)
- **S03 구조 벽체:** 벽체 경유/비경유 지점 비교. 단일 벽체 효과로 단정하지 않음
- **S04 공간 점유:** 허가된 환경에서 비점유/점유 상태 반복 비교
- **S05 자재 배치:** 이동 가능한 자재의 배치 전후 비교(안전 확보 시)

## 5. 개념 모델

```text
PL_est(d) = PL(d0) + 10n·log10(d/d0) + ΣL_obstacle + L_occupancy
RSSI_감소량(dB) = 기준조건 RSSI 중앙값 - 변경조건 RSSI 중앙값
```

이는 **연구 가설용 단순 모델**이지 검증된 전파 해석기가 아닙니다. 반사·회절·다중경로로 인해 가산 모델이 맞지 않을 수 있습니다. 감소량이 양수라도 특정 재료의 인과적 감쇠라고 단정할 수 없습니다.

## 6. 제안 데이터 구조(현재 API 미구현 필드 포함)

```text
floor_id, floorplan_version, coordinate_system, scale_m_per_unit,
point_id, x_m, y_m, z_m, ap_id, bssid, scenario_id,
material_type, thickness_mm, occupancy_count, occupancy_area_m2,
source_type, measured_at, received_at, rssi_dbm
```

인원 밀도 후보 지표는 `occupancy_count / occupancy_area_m2`입니다. 좌표·시나리오·출처 유형은 **현재 측정 API에 아직 추가되지 않았습니다.**

## 7. 건축 산출물과 제약
축척이 확인된 평면도, 벽체·자재 범례, 측정점 배치도, 조건별 비교 도면, 원시 측정값 기반 포인트 지도, 가상/추정값 범례를 작성합니다. 도면 사용 권한 및 버전·작성자·검토 일자를 기록합니다.

ESP32-WROOM-32는 2.4 GHz만 측정합니다. RSSI는 장치 방향·AP 출력·시간·다중경로에 따라 변합니다. 점 사이를 보간한 히트맵은 **추정 결과**이지 실측 지도가 아닙니다.
